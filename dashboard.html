        Connect real data

        This site is static (GitHub Pages), so there are no server logs. To see real visitors you need a small counter:

        • GoatCounter — free, open source. Add one script line to the five site pages, then we wire its API key into getAnalyticsData(). Privacy-friendly, no cookies.
